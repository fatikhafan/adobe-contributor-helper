# ⚡ Adobe Contributor All-in-One Helper

Aplikasi web berbasis Streamlit untuk membantu kontributor Adobe Stock dalam mengelola proses unggah aset secara otomatis maupun manual.

## 🔗 Tautan Aplikasi
* **Aplikasi Live:** [Adobe Contributor Helper](https://adobe-contributor-apper-gudpkev5nkps4xxadevdpx.streamlit.app/)

## ✨ Fitur Utama
1. **AI Metadata Generation:** Pembuatan Judul (*Title*) dan Keywords otomatis menggunakan Google Gemini AI dengan dukungan multi-bahasa (English, Bahasa Indonesia, Français, Deutsch, dll.)[cite: 8].
2. **Smart AI Sharp Upscale:** Peningkatan resolusi gambar (opsi 2x, 4x, 8x) lengkap dengan filter penajaman (*sharpening*) dan kontras agar memenuhi standar minimum Adobe Stock (di atas 4 MP / sisi terkecil 2000 px).
3. **Interactive Comparison Slider:** Fitur geser kanan-kiri interaktif untuk membandingkan foto asli sebelum dan sesudah *upscale*.
4. **Dual-Mode Upload:**
   * **Manual Mode:** Download file hasil *upscale* ke perangkat dan salin teks metadata (*copy-paste*) secara manual ke dasbor Adobe Stock[cite: 10].
   * **Auto Mode:** Unggah file secara langsung ke Adobe Stock menggunakan kredensial FTP/SFTP.
5. **AI Fallback Mechanism:** Penanganan otomatis untuk kestabilan koneksi model AI Gemini.
